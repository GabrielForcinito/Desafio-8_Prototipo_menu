# 🔗 Desafio Navegação

## 📌 Sobre o projeto

Projeto desenvolvido em HTML com o objetivo de praticar a navegação entre páginas, utilizando links internos para simular a estrutura básica de um site.

## 🛠️ Tecnologias utilizadas

* HTML5

## 🎯 Funcionalidades

* Navegação entre múltiplas páginas
* Uso de links internos
* Estrutura básica de site
