# 🔗 Desafio Navegação

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar a **navegação entre páginas HTML**, utilizando links internos para simular a estrutura básica de um site.

## 💻 Como executar

### 🔹 Opção 1: Acessar online

Acesse diretamente pelo navegador:

👉 Link disponível na seção **About** do repositório

### 🔹 Opção 2: Rodar localmente

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` no navegador
